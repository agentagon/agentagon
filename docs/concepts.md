# Product concepts

| Concept | Responsibility |
|---|---|
| Dashboard | Human interface to agents, goals, issues, workflows, tasks, memory and settings |
| Brain | Managed Codex/Claude reasoning and independent review |
| Memory | Named local groups for improvement lessons and target-agent knowledge |
| Workflows | Built-in Discover issues, Fix and Optimize journeys plus evaluation, baseline and full Audit |
| Capabilities | Shared trace, execution, evaluation, optimization, Git and delivery operations |

MCP is another interface to the same local service. An Agent is the application being improved. A Goal describes a broader objective. An Issue describes a supported problem and its occurrences. A Workflow defines a procedure; a Task is one durable execution. A MemoryGroup binds a knowledge purpose, folder and explicit access.

## Production feedback

Production adds Improvement, Deployment, Monitor and Observation records beneath each agent. They keep verification, user selection, deployment and observed outcomes separate. See [production monitoring](production.md) for the two connected improvement loops.
