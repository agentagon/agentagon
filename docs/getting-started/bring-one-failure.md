# Bring one failure

Choose **All issues** from Overview or an agent workspace. Paste or upload supported JSON/JSONL, or select a connection and enter a provider trace ID.

1. Choose **Check trace**. Nothing is retained yet.
2. Review the detected format, usable spans, coverage, redaction, and blockers.
3. Choose **Import and prepare fix** for this failure, or **Import and investigate** when the trace may contain several issues.
4. Confirm the owning agent. Save reviewed expected behavior when the evidence does not establish it.
5. Review the prepared action before starting Fix.

Changing the trace data invalidates its preview. Unsupported or zero-span input cannot be imported for diagnosis. A saved goal and full audit are optional.
