# Inspect shared activity and results

The dashboard and MCP use the same service-owned tasks, questions, result decisions, deliveries, monitors, and observations. The sidebar labels the task workspace **Activity** and groups records into **Needs you**, **Running**, **Finished**, and **All**.

Open a running activity for its current durable stage, budget, retained evidence, and explicit controls. Closing its drawer leaves it running. Cancellation and resume use the task runtime; reconnecting the browser never resumes interrupted work automatically.

Finished Fix and Optimize activities link to a full result page. Review the measured comparison, exact candidate diff, verification checks, independent review, limitations, and other attempts before recording a choice. A task recommendation is advisory until **Select this change** or **Keep current version** records a user decision. Local delivery is available only for an eligible selected result.

Raw host events and structured result data remain under collapsed diagnostics. They are evidence for debugging, not the primary customer result.
