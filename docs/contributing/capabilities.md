# Implementation map

Use this reference to locate the contracts, source and representative tests behind each capability. Start with the [capability overview](../capabilities.md) for usage and [product decisions](product-decisions.md) for design rationale.

For a connected explanation of these components, read [how Agentagon works](architecture.md). The [extension walkthrough](extending.md) demonstrates a proposed change through normalization, validation and retained measurements.

Capability IDs remain stable when files move. Test links identify relevant coverage; record actual validation results with the revision and environment in the PR or release record.

## 1. Review and audit

Entry points: `ag:review`, `ag:audit`; CLI `audit changes`, `start`, `prepare`, `submit`, `report`. See [review and audit](../audit.md) and the [scope decisions](product-decisions.md#separate-triggers-define-the-evidence-scope).

| Capability | Observable behavior and conditions | Implementation / representative tests |
|---|---|---|
| **AUD-01 · Review local changes** | Capture staged, unstaged and non-ignored new files against `HEAD`, including an empty initial baseline. Findings concern the captured changes; empty or excluded-only input cannot establish a clean full application. | [Change snapshots](../../src/agentagon/storage/changes.py), [review procedure](../../skills/review/SKILL.md); [snapshot tests](../../tests/test_changes.py), [review flow](../../tests/test_review_flow.py) |
| **AUD-02 · Audit a local application** | Inspect code, traces or both, with optional path filters. Full audits accept directories without Git and uncommitted code; trace alignment limitations are warned and retained. A goal changes emphasis while required rubric coverage remains fixed. | [Operations](../../src/agentagon/operations.py), [audit procedure](../../skills/audit/SKILL.md); [audit tests](../../tests/test_audit.py), [goal and mode tests](../../tests/test_product_flow.py) |
| **AUD-03 · Validate evidence and conclusions** | Prepare bounded evidence, diagnosis and clustering packets. Validate required judgments, citations, flag dispositions and finding scope before accepting responses. | [Analysis](../../src/agentagon/core/analysis.py), [submission schema](../../contracts/v1/submission.json), [rubric](../../signals/audit-v1.json); [audit tests](../../tests/test_audit.py), [edge cases](../../tests/test_edge_cases.py) |
| **AUD-04 · Recommend improvements and eval coverage** | Report defects, improvement opportunities and specific eval cases, including when no defect is found. Recommendations identify behavior and expected checks; review/audit do not implement or execute them. | [Review procedure](../../skills/review/SKILL.md), [reporting](../../src/agentagon/reporting.py); [review flow](../../tests/test_review_flow.py), [review reports](../../tests/test_review_reporting.py) |
| **AUD-05 · Resume without changing evidence** | Retain stage progress and historical reports. Reject stale submissions and changed captured inputs; require a new review/audit for changed evidence. | [Workspace](../../src/agentagon/storage/workspace.py), [operations](../../src/agentagon/operations.py); [audit resumption](../../tests/test_audit.py), [changed-input tests](../../tests/test_review_flow.py) |

## 2. Runtime evidence

Trace retrieval is performed by the coding agent through available provider tools. The CLI plans selection and imports exports; it is not a production trace collector. See [acquisition](../../skills/audit/references/acquisition.md) and [supported formats](../../skills/audit/references/formats.md).

| Capability | Observable behavior and conditions | Implementation / representative tests |
|---|---|---|
| **TRACE-01 · Select bounded trace evidence** | Use explicit provider/project, time window and trace count; select root IDs from provider metadata and retain acquisition completeness. | [Selection](../../src/agentagon/telemetry/selection.py), [acquisition schema](../../contracts/v1/acquisition.json); [selection tests](../../tests/test_selection.py) |
| **TRACE-02 · Normalize provider exports** | Import Braintrust, Langfuse, LangSmith, Phoenix and OpenTelemetry formats into versioned trace records, retaining provenance and redacting recognized secrets. | [Ingestion](../../src/agentagon/telemetry/ingest.py), [normalization](../../src/agentagon/telemetry/normalize.py), [trace schema](../../contracts/v1/trace.json); [telemetry tests](../../tests/test_telemetry.py) |
| **TRACE-03 · Calculate runtime measurements** | Derive timing, errors, tool behavior and available token/cost measurements. Preserve unknown values and avoid summing overlapping parent/child usage as independent costs. | [Signals](../../src/agentagon/core/signals.py), [analysis rules](../../skills/audit/references/analysis.md); [telemetry tests](../../tests/test_telemetry.py), [edge cases](../../tests/test_edge_cases.py) |
| **TRACE-04 · Correlate traces with code** | Retain the assumption that supplied traces belong to the captured revision. Conflicting metadata prevents unsupported correlation; changes reviews require a connection to captured changes. | [Alignment](../../src/agentagon/telemetry/alignment.py), [operations](../../src/agentagon/operations.py); [alignment tests](../../tests/test_trace_alignment.py), [combined review tests](../../tests/test_review_flow.py) |

## 3. Evaluation preparation

Entry point: `ag:eval`; CLI `eval start`, `lookup`, `check`, `freeze`, `status`. Requires a clean committed source, a named execution profile, preparation limits and trustworthy expected behavior. See [evaluation preparation](../eval.md).

| Capability | Observable behavior and conditions | Implementation / representative tests |
|---|---|---|
| **EVAL-01 · Build or extend a benchmark** | Start from a goal, findings or review recommendations. The host edits an isolated preparation worktree using existing tests and permitted data; application source stays unchanged. | [Preparation](../../src/agentagon/experiments/preparation.py), [eval procedure](../../skills/eval/SKILL.md); [preparation tests](../../tests/test_evaluation_preparation.py) |
| **EVAL-02 · Check benchmark sensitivity** | Execute baseline and deliberately incorrect cases against declared expectations. Optional correct variants must demonstrate declared objective rankings and minimum separation. Crashed or vacuous checks cannot establish sensitivity. Preparation has its own trial/time budget and retry identities. | [Preparation](../../src/agentagon/experiments/preparation.py), [plan schema](../../contracts/v1/evaluation-plan.json), [budget schema](../../contracts/v1/evaluation-budget.json); [sensitivity and retry tests](../../tests/test_evaluation_preparation.py), [metric discrimination tests](../../tests/test_metric_discrimination.py) |
| **EVAL-03 · Independently review and freeze** | Bind source, files, inputs, seeds, metrics, coverage, execution evidence and independent review into a frozen package. Missing ground truth or review leaves preparation incomplete. | [Preparation](../../src/agentagon/experiments/preparation.py), [review schema](../../contracts/v1/evaluation-review.json); [review and freeze tests](../../tests/test_evaluation_preparation.py) |
| **EVAL-04 · Reuse and version an evaluation** | Produce a benchmark review branch and fix specification. Private inputs stay out of delivery; intended tests require declared delivery paths. `eval start --from` creates a new draft; `fix start --evaluation` requires matching source and measures a fresh baseline. | [Preparation](../../src/agentagon/experiments/preparation.py), [engine](../../src/agentagon/experiments/engine.py); [package and holdout tests](../../tests/test_evaluation_preparation.py) |

## 4. Measured improvements

Entry point: `ag:fix`; CLI `fix start`, `lookup`, `new`, `run`, `select`, `stop`. Use a prepared evaluation or an explicit specification, a clean committed checkout and a saved profile with chosen limits. See [measured fixes](../fix.md) and the [specification contract](../../skills/fix/references/contract.md).

| Capability | Observable behavior and conditions | Implementation / representative tests |
|---|---|---|
| **FIX-01 · Freeze the experiment** | Start from issues, a goal or both. Freeze editable/evaluation paths, inputs, overlays, checks, metrics, constraints, repetitions, seeds and execution profile before baseline measurement. | [Specification](../../src/agentagon/experiments/spec.py), [engine](../../src/agentagon/experiments/engine.py), [fix schema](../../contracts/v1/fix-spec.json); [contract tests](../../tests/test_fix_contracts.py), [experiment tests](../../tests/test_experiments.py) |
| **FIX-02 · Isolate and retain candidates** | Create candidate worktrees from eligible recorded parents; seal execution snapshots and retain Git references. Reject edits outside scope or to protected evaluators. | [Checkouts](../../src/agentagon/experiments/checkouts.py), [engine](../../src/agentagon/experiments/engine.py); [experiment tests](../../tests/test_experiments.py) |
| **FIX-03 · Measure checks and objectives** | Execute declared commands and collect engine-bound results. Optional preflight checks skip expensive work on unexpected failure, retaining skipped commands without admitting partial metrics. Require all repetitions and finite declared metrics; report median and observed range. Apply absolute or original-baseline-relative constraints. | [Engine](../../src/agentagon/experiments/engine.py), [evaluation](../../src/agentagon/experiments/evaluation.py); [experiment tests](../../tests/test_experiments.py), [preflight tests](../../tests/test_preflight.py), [fix reports](../../tests/test_fix_reporting.py) |
| **FIX-04 · Verify candidates independently** | Bind a review by someone other than the author to the sealed source and trial evidence. Require machine feasibility and accepted independent review before candidate frontier admission. | [Engine](../../src/agentagon/experiments/engine.py), [review schema](../../contracts/v1/fix-review.json); [experiment tests](../../tests/test_experiments.py), [ordering tests](../../tests/test_experiment_ordering.py) |
| **FIX-05 · Preserve objective tradeoffs** | Keep the verified Pareto frontier across declared objectives. Search preference does not replace verification or select a final winner implicitly. | [Evaluation](../../src/agentagon/experiments/evaluation.py); [experiment tests](../../tests/test_experiments.py), [search tests](../../tests/test_experiment_search.py) |
| **FIX-06 · Bound, stop and recover work** | Enforce shared candidate/trial/time/concurrency budgets. Stop owned execution; explicit continuation resumes recorded work. Uncertain delivery reconciles existing trials rather than buying another execution. | [Engine](../../src/agentagon/experiments/engine.py), [run store](../../src/agentagon/experiments/store.py); [recovery tests](../../tests/test_experiment_recovery.py), [ordering tests](../../tests/test_experiment_ordering.py) |

## 5. Execution, coordination and learning

These capabilities use saved profile settings and the active coding host. See [runner setup](../reference/fix.md#configure-execution-once), [search](../reference/fix.md#choose-how-to-explore), [orchestration](../orchestration.md) and [lessons](../reference/fix.md#learn-from-completed-experiments).

| Capability | Observable behavior and conditions | Implementation / representative tests |
|---|---|---|
| **EXEC-01 · Execute locally** | Run checks on the current host against isolated source. Worktrees protect origin files but do not provide a machine/network sandbox. Parallel trials need actual independent capacity. | [Runners](../../src/agentagon/experiments/runners.py), [worker](../../src/agentagon/experiments/worker.py); [runner tests](../../tests/test_experiment_runners.py) |
| **EXEC-02 · Execute over SSH or E2B** | Transfer frozen execution inputs to a configured destination, collect bound evidence, reconcile interrupted jobs and clean up owned resources. SSH needs an existing host; E2B needs its optional dependency, template and key. | [Runners](../../src/agentagon/experiments/runners.py), [worker](../../src/agentagon/experiments/worker.py); [simulated runner tests](../../tests/test_experiment_runners.py), [opt-in live tests](../../tests/test_live_fix.py) |
| **EXEC-03 · Record task diagnostics** | Python/Node helpers or direct JSONL record task progress, inputs, outputs, failures and artifacts. Retention is bounded and redacted; these diagnostics do not supply scores or pass checks. Local mirrors support inspection without reconnecting to workers. | [Worker](../../src/agentagon/experiments/worker.py), [event contract](../../contracts/v1/task-event.json), [helper guide](../task-evidence.md); [task evidence tests](../../tests/test_task_evidence.py) |
| **COORD-01 · Choose search parents** | Support `pareto`, `argmax`, `top_k`, `epsilon_greedy`, `softmax` and `pareto_per_task`. Scalar strategies need a named objective; task specialists need frozen task metrics. Record seeded decisions and policy changes. | [Search](../../src/agentagon/experiments/search.py); [search tests](../../tests/test_experiment_search.py) |
| **COORD-02 · Coordinate parallel branches** | Reserve durable rounds, candidates, author/reviewer work and branch depth within host/resource/run capacity. Record host assignments and reuse reservations after interruptions. Work waits when the host is unavailable. | [Orchestration](../../src/agentagon/experiments/orchestration.py), [round schema](../../contracts/v1/fix-round.json), [role contract](../../skills/fix/references/roles.md); [round tests](../../tests/test_host_rounds.py) |
| **COORD-03 · Steer an active run** | Change future search policy; queue directives, expansion or continuation; stop/select; cancel queued work; invalidate evidence or exhaust an approach. Revision checks and operation IDs protect retries. Authoring work needs host acknowledgment. | [Controls](../../src/agentagon/experiments/controls.py), [control schema](../../contracts/v1/fix-control.json); [control tests](../../tests/test_fix_controls.py) |
| **COORD-04 · Retain lessons from completed work** | Optional bounded scans retain failure patterns, unsuccessful hypotheses and follow-ups with evidence and uncertainty. Same-checkout lessons inform later authors/reviewers without replacing fresh verification. | [Learning](../../src/agentagon/experiments/learning.py); [learning tests](../../tests/test_experiment_learning.py), [shared scan budgets](../../tests/test_host_rounds.py) |
| **COORD-05 · Resume through native lifecycle hooks** | Bind continuation context to the active session; respect pause, stop and pending user input. Session startup does not launch work. Hook trust and callback support remain host-controlled; unavailable callbacks require manual resume. | [Hooks](../../src/agentagon/experiments/hooks.py), [native hook bundle](../../hooks/hooks.json); [continuation tests](../../tests/test_continuation_hooks.py) |

## 6. Selection and delivery

Entry points: `fix select`, `ag:ship`; CLI `fix cleanup`, `fix ship`. See the [shipping procedure](../../skills/ship/SKILL.md).

| Capability | Observable behavior and conditions | Implementation / representative tests |
|---|---|---|
| **SHIP-01 · Select a verified branch** | Turn the user's selected frontier candidate into a reviewable branch. Preserve the origin checkout and retained alternatives. | **SHIP-02 · Clean and reverify delivery** | Reserve cleanup as a separate candidate under the existing budget and frozen evaluation. Require new execution and independent review. Automatic substitution requires frontier admission and no worse results on every frozen objective. | [Cleanup](../../src/agentagon/experiments/cleanup.py), [ship procedure](../../skills/ship/SKILL.md); [cleanup tests](../../tests/test_shipping_cleanup.py) |
| **SHIP-03 · Prepare a local delivery package** | Produce the exact selected patch, diffstat, measurement summary and draft PR body. Recheck selection/evidence and preserve unrelated work; omit private execution material from the PR body. | [Delivery](../../src/agentagon/experiments/delivery.py); [delivery tests](../../tests/test_fix_delivery.py) |
| **SHIP-04 · Publish a GitHub draft PR** | With authorized destination, authenticated `gh` and explicit publication, push the selected branch and create a draft PR. Retry receipts reconcile prior success; changed source/base requires fresh verification. | [Delivery](../../src/agentagon/experiments/delivery.py); [simulated publication tests](../../tests/test_fix_delivery.py) |
