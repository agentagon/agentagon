# Prepare optimization context

Input: accepted goal and measurement design, frozen baseline, scoped failure analysis and optional approved Intelligence receipt.

Assemble supported observations, representative development failures and successes, constraints, code-scope limits and unresolved hypotheses. Cite retained sources and distinguish Intelligence guidance from measured evidence. Intelligence uses its existing consent and redaction flow; no raw code, traces or goal is uploaded automatically. Guidance can be omitted without blocking local work.

App-managed runs receive an immutable background file prepared from the accepted design. Pass it unchanged to `fix optimize --background-file`; use the accepted finalist count and concurrency. Do not edit background midway through a run. New guidance requires a newly accepted context and run.

GEPA owns proposal formatting, extraction and search. Supply context through its upstream `background` and new execution observations through evaluator feedback. Never reconstruct its reflection prompt or install a custom proposer. [Native-host protocol](../optimize/references/native-host.md) preserves exact request/session identities.
