# Define an agent goal

Input: confirmed agent scope, stated outcome, optional issue or trace selection.

Separate the application's responsibility from the requested improvement. Preserve arbitrary user goals; categories are suggestions. Identify measurable success, unacceptable regressions, and assumptions that need an answer. Ask only when missing expectations materially change the evaluation.

Output: a concise goal and proposed behaviors with their authority (requirement, trusted example, existing assertion, or user decision). Trace observations describe what happened; they do not supply correct labels. Goals and behavior definitions remain available without a provider connection. Mark trajectory-dependent measurements as needing imported traces or instrumented evaluation executions.

Proceed to [measurement design](design-measurement.md). A full audit is optional when the goal and evidence are already sufficient.
